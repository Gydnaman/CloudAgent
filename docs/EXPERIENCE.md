## Foundation

响应式 Web 工作台，前端使用 Vue 3、TypeScript 和 Vue Router。用户通过本机浏览器访问页面；客服流程使用合成身份、固定 Mock 模型、Mock 知识源和只读 Mock 工具。`DESIGN.md` 是视觉身份依据；页面行为和状态由本文件约定。

## Information Architecture

| 页面 | 进入方式 | 作用 |
| --- | --- | --- |
| 演示操作面板 / 客服工作台 | 打开首页 | 首次使用时说明演示边界、创建会话、选择示例；会话开始后提供聊天、时间线、依据和工具结果 |
| 运行详情 | 聊天区的“查看完整详情” | 查看指定 Agent 运行的持久事件、状态和错误信息 |
| 模型与服务状态 | 左侧导航 | 查看 Mock 可用状态和 Live 尚未接入状态 |
| 知识源与工具 | 左侧导航 | 查看本地合成资料与只读 Mock 工具的范围 |

桌面端左侧为导航；窄屏导航移至页面顶部。所有页面均显示本地 DEMO / MOCK 边界。

## Voice and Tone

使用简体中文和具体动作说明。先讲用户能观察到什么，再出现 Agent、Fixture、SSE 等技术词。按钮使用“创建空白演示会话”“载入示例”“发送问题”等直接文本。失败信息说明发生了什么以及可做的下一步；状态不单靠颜色表达。

## Component Patterns

- **演示模式条**：展示本机、Mock、合成资料和只读工具等固定模式；它们是能力范围说明，不代表后端健康探测结果。
- **身份选择**：显示“小林 · 产品用户”或“小陈 · 产品用户”等合成身份标签，不暗示真实登录；开始空白会话或加载示例前必须先选择身份。
- **示例场景**：覆盖知识命中、本人用量允许、他人用量拒绝、知识为空和范围外问题。首次页面的示例卡片会创建会话并填入对应问题，不会自动发送；用户可以先编辑，再显式点击发送。
- **聊天输入**：始终有可见标签，显示当前输入的 Unicode 码点数；初始化、关闭会话或运行中时禁用输入与相关动作。
- **运行时间线**：按持久事件 sequence 顺序展示路由、Agent、知识、工具授权和终态；每项包含事件名称、时间及可读摘要。
- **依据与工具结果**：区分知识来源、授权决定、工具结果和“工具未执行”。拒绝时明确说明未执行。
- **导航与跳转**：完整运行详情链接仅在存在运行编号时显示；运行编号不作为会话凭据使用。

## State Patterns

| 状态 | 页面反馈 |
| --- | --- |
| 首次载入 | 获取合成身份列表；主操作显示“正在连接本地服务…”，不可重复提交 |
| 尚无会话 | 显示介绍、运行模式、处理步骤、示例问题和其他页面入口；不显示空白聊天区 |
| 已创建空白会话 | 显示聊天输入及建议问题，提示用户发送后右侧才会出现运行步骤 |
| 示例载入 | 显示已创建会话和已预填提示；明确示例没有自动发送 |
| 运行中 | 禁用重复发送，显示逐步回答和事件时间线；允许停止当前运行 |
| 结果待确认 | 明确告知页面正在按运行编号补查已保存事件；不把流结束误当作任务成功 |
| 运行完成/失败/取消 | 依据持久终态更新页面；保留已收到的消息和时间线 |
| 授权拒绝 | 显示拒绝决定及“工具未执行”，不展示越权资源内容 |
| 知识为空/不支持 | 说明缺少资料或请求不在演示范围，不编造事实或调用工具 |
| API 错误 | 页面顶部使用 `role="alert"` 显示可理解信息；可重试的页面保留重试入口 |
| 会话关闭 | 显示关闭状态并禁用输入；允许查看本地已有的运行记录 |

## Interaction Primitives

- 创建会话时从服务端返回的合成身份清单中选择主体；创建后焦点移到客服输入框。演示 token 只放在 `sessionStorage`，通过 `X-Demo-Session-Token` 请求头传递，不显示在界面或 URL 中。
- 示例卡片创建一个会话并预填问题，不代替用户发送；创建或载入后焦点移到输入框，发送前用户可以编辑文本。
- 消息按 NFC 规范化并裁剪首尾空白，长度限制为 1 至 4,000 个码点；发送使用 UUID 幂等键，重试沿用原键。
- SSE 事件先由服务端持久化，再发送给页面。若流在终态前结束，页面显示待确认并按 `run_id` 读取状态和事件。
- 发送后先播报“正在处理”；终态播报只说明完成、失败或取消，不重复朗读整段回答。
- 运行详情展示本次读取时的状态快照；状态仍为运行中时，用户可重新加载状态和事件。
- 停止操作取消当前运行；关闭会话时显示服务端返回的取消终态。关闭后禁止继续发送。
- 页面在会话 token 有效期内可恢复会话；token 自创建起 8 小时过期。

## Accessibility Floor

- 页面提供“跳转到主要内容”链接；所有交互均可通过键盘到达，焦点轮廓使用 `{colors.brand}` 系列并保持可见。
- 按钮和链接有清楚的文字名称；身份和消息输入有显式标签。示例卡片使用原生 button，不依赖 hover 或鼠标拖动。
- 错误通过 `role="alert"` 通知；示例载入、消息和运行状态通过可读文本或 `role="status"` 呈现。
- 禁止只用颜色表达允许、拒绝、等待或故障；状态文字与 `{colors.success}`、`{colors.warning}`、`{colors.danger}` 同时出现。
- 尊重 `prefers-reduced-motion`；触控目标至少 44px，窄屏正文和输入保持可读字号。

## Responsive & Platform

| 窗口宽度 | 行为 |
| --- | --- |
| `> 1200px` | 左侧导航；首次使用面板按介绍/启动、模式、步骤、场景分区；会话区并排显示聊天和 Agent 侧栏 |
| `981–1200px` | 收窄导航和内容边距；示例卡片换成较少列数 |
| `701–980px` | 启动介绍和身份表单上下排列；会话时间线和依据卡片移至聊天下方 |
| `391–700px` | 导航移到顶部；模式卡片双列；示例卡片双列；运行内容单列 |
| `≤ 390px` | 场景和步骤卡片单列；发送、停止、关闭和切换身份按钮铺满可用宽度，不出现横向滚动 |

## Key Flows

### 首次体验：演示操作者小林观察产品问答

1. 小林在本机启动 Compose，并打开 `http://127.0.0.1:8000`。
2. 操作面板说明这是本地 Mock 演示，展示 Agent 的处理步骤和可体验场景。
3. 小林选择合成身份，点击“产品支持哪些部署版本？”示例卡片。
4. 页面创建会话并把问题放入输入框，清楚提示它尚未发送；小林确认后点击“发送问题”。
5. 页面显示 Mock 回答、本地知识引用和右侧事件时间线。
6. **高潮：**小林能从引用和时间线中看见回答来自哪条演示资料、Agent 经过哪些步骤，不需要猜测 Agent 是否真实调用了系统。

### 查看权限边界：小林验证只读工具拒绝

1. 小林点击“查询其他账户用量”场景，确认示例问题后发送。
2. Agent 请求访问不属于当前合成身份的账户。
3. 服务端策略拒绝访问，记录拒绝事件并跳过工具调用。
4. 页面在时间线和工具结果区显示“拒绝”与“工具未执行”，最终回答说明原因。
5. **高潮：**小林能从可见事件确认越权读取没有执行，而不只是看到一条含糊的失败答复。

### 遇到无资料问题：小林确认系统不会补造答案

1. 小林加载“产品的 SLA 是多少？”示例并显式发送。
2. 本地知识源没有匹配资料。
3. 页面显示知识结果为空和明确说明；没有工具调用，也不会生成看似确定的 SLA。
4. **高潮：**小林能区分“系统没有证据”与“系统找到资料”，并知道这只是当前演示数据范围。
